# TravelWorld - Веб застосунок для подорожей 🌍✈️

Ласкаво просимо до TravelWorld - вашого надійного партнера у світі подорожей!

## 📋 Опис проєкту

TravelWorld - це сучасний веб застосунок для пошуку та бронювання подорожей по всьому світу. Застосунок пропонує:

- 🌏 200+ країн світу для мандрівок
- ⭐ 4.9 середній рейтинг від клієнтів
- 🎯 5000+ унікальних турів
- 👥 150,000+ щасливих мандрівників

## 🚀 Швидкий старт

### Встановлення залежностей

```bash
npm install
```

### Запуск у режимі розробки

```bash
npm start
```

Застосунок автоматично відкриється у вашому браузері за адресою `http://localhost:8080`

### Збірка для продакшену

```bash
npm run build
```

Готові файли будуть у папці `dist/`

## 🏗️ Структура проєкту

```
/workspace
├── src/
│   ├── index.html          # Головна HTML сторінка
│   ├── assets/
│   │   ├── css/           # Скомпільовані CSS файли
│   │   ├── scss/          # SCSS стилі
│   │   ├── js/            # JavaScript модулі
│   │   ├── images/        # Зображення та графіка
│   │   └── fonts/         # Шрифти ClashDisplay
├── dist/                  # Зібрані файли (після npm run build)
├── package.json          # Залежності проєкту
└── webpack.config.js     # Конфігурація Webpack
```

- **HTML5** - семантична розмітка

## 📦 Основні залежності

### Production
- `gsap` - анімаційна бібліотека
- `locomotive-scroll` - smooth scrolling
- `@studio-freight/lenis` - smooth scroll engine

### Development
- `webpack` - module bundler
- `sass` - CSS preprocessor
- `babel` - JavaScript compiler
- `mini-css-extract-plugin` - CSS extraction
- `imagemin` - оптимізація зображень
